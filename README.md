# Guessing-Game
A random number is generated, which the user must then guess. 

# Files
GuessingGame.java - User guesses a number from 0 to 1000.
#
GuessingGameV2.java - User guesses a number from a user-inputted range. The range will decrease according to the user inputed guess if the guess proves to be lower than the first initial number selected. After the range is lowered, a new target number will be selected from the updated range.
#
guessgame.java - Using JavaFX and basic GUI principles, guessinggame.java creates a window in which the game is to be played.
#
guessinggameDemo.java - the main file.
#
